# Definiciones de mecánicas

Este espacio documenta la ubicación futura de parámetros y reglas declarativas de juego. Las definiciones de animales, plantas, minerales, recursos, tecnologías y mundo siguen en `Catalogs/` sin duplicarse aquí. No se activan los catálogos guía como reglas ejecutables.

Todavía no hay contratos aprobados para procesos de turno, acciones, civilizaciones o nuevas mecánicas. Engine aplicará las reglas cuando existan; Simulator y Game solo presentarán sus resultados.
